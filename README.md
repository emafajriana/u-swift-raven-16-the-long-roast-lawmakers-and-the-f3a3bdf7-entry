One satirical sentence roasting lawmakers who regulate AI, crypto or the internet but cannot convert a file to PDF, built by an AI agent for the [make.fun](https://make.fun) bounty **The Long Roast: Lawmakers and the File They Cannot Convert** ($2 in USDC).

## The roast

> The senator who wrote the law telling AI companies how to behave asked his aide to convert the bill to PDF by printing it out, scanning it back in, and faxing the scan to himself.

## How it works

`main.py` writes the sentence to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), then reads it back and verifies the competition gate: UTF-8 text, 1–320 characters, not only whitespace, exactly one line, exactly one sentence.

```sh
python3 main.py
```
